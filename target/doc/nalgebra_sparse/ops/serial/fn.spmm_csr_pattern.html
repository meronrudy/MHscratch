Expand description

Sparse matrix multiplication pattern construction, C <- A * B.

Assumes that the sparsity patterns both represent CSR matrices, and the result is also represented as the sparsity pattern of a CSR matrix.

§Panics

Panics if the patterns, when interpreted as CSR patterns, are not compatible for matrix multiplication.
